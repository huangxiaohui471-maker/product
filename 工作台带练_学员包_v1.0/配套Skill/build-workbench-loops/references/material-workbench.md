# 讲师素材底版：运行与改造边界

仅在实际处理讲师底版时读取。优先看同包素材工作台/SKILL.md、README.md及当前代码，不能只靠历史截图判断。

## 已有四个工作区

素材与拆解、我的内容、数据与复盘、我的业务。浏览从库/列表进入，选中对象后看详情或编辑；参考和旧版按需对照。苹果式浅色工具界面是本样例的选择，不要求其他业务照搬。

工作台先承载查看、判断和操作。用户看完数据可以结束，不强制进入下一轮派工。搭建的三循环不是业务前台的栏目；工作台与飞轮持续运行属于后续教学。

## 它怎样运行

这是本地应用，网页可以展示、编辑、保存资料与请求。语义任务采用“页面存请求 → 宿主Agent执行 → 回写结果 → 页面刷新”。不是常驻模型服务；当前搜索、采集、模型等能力以项目内实际接入为准，不冒称全部自动。

相近工作可保留原能力和运行方式；不同业务可以只复用适用的交互与结构，由WB搭建师做符合任务的页面。改造前分清能力是实际接通、待Agent接续还是演示，学员无需了解接口细节，但必须知道如何继续做。

## WorkBuddy组合使用

先在WB首页点“个人工作台”，再引用本教练、讲师底版和学员资料。搭建师已经加载时直接按教练节奏工作，不再虚构另一个专家调用。是否使用云端能力由用户范围、业务需要和实际工具决定，不因专家默认路线而扩大课堂首版。

本机Hy3已按这个入口开展真实对话测试；“将Skill文件作为项目资料读取”与“已全局安装、可自动发现”不同。未经实际验证，不宣称跨宿主安装成功。

## 保留什么

不把讲师的素材、公司信息、历史成绩变成学员的事实。保留学员已有业务资料、用户修改、内容版本和数据归属；页面改版不要清空浏览器或项目数据来掩盖迁移问题。学员若导入同一资料，先按业务身份判断重复，而不是叠加出多份假记录。

每次测试区分：真实软件运行、合成测试数据、实际业务效果。门店日报演练使用合成数据，不能称已在真实门店验证。
