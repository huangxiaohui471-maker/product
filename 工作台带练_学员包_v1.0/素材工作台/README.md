# 学员工作台底版

先看包根目录“先看这里.html”。优先在WB首页点“个人工作台”，交给它整个包和自己的资料。
根目录 `启动底版.py` 会把业务数据保存在 `我的工作台/`，所有Mac启动入口指向同一目录。
直接运行 `server.py` 时请显式指定 `--project ../我的工作台`。不要双击web/index.html冒充完整运行。

四个现成工作区：素材与拆解、我的内容、数据与复盘、我的业务。列表、详情、保存、版本等代码保留，素材和业务记录为空是正常的。
按自己的工作改造，不强制保留栏目。页面中AI请求需要宿主Agent执行并回写，具体方式见SKILL.md和references/agent-actions.md。
Python 3.10+即可启动空白工作台；视频处理、在线搜索等依赖只在需要时配置。没有老师的视频、账号或模型额度。
