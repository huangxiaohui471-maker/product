# 销售内容生产线

这条生产线把已经确定的企业理解和本次内容方向，做成能直接使用的销售内容。它由两段能力组成，但前台只呈现一条生产线。

## 一、先装配销售底稿，不重做企业调研

优先读取企业白皮书中的五组原料：

1. 客户：主要人群、表面问题、真正病根、希望得到的具体结果；
2. 场景：本轮最值得解决的具体时刻，以及为什么优先；
3. 方案：客户拿什么比较、我们的关键不同、能够使用的证明；
4. 行动：谁参与决定、最大的行动阻力、怎样降低阻力、希望迈出的下一步；
5. 阵地：内容出现的渠道、位置、业务任务和表达边界。

再用 `strategy_to_production/v1` 补入本轮目标对象、客户场景、希望改变的想法、行动目标、采用的素材机制和本次只测试的一处变化。

将两者装配成一份内部销售底稿：

- 这次对谁说；
- 他正处在什么具体时刻；
- 他真正想解决什么；
- 他为什么会选我们；
- 什么事实可以证明；
- 他最可能因为什么不行动；
- 这次先化解哪一个阻力；
- 看完希望他做什么。

白皮书已有的内容直接用，不重新提问、不重复生成用户画像、FABE或行动成本文件。缺失项按以下顺序处理：已有资料推导且不改变方向 → 标为当前判断继续；可用保守表达绕开 → 保守表达；只有会令客户、承诺或销售方向发生反转时 → 一次只问一个问题。

这一步继承 `S 营销策划生产线 v2.1` 的核心能力，但取消原版逐模块出文件和两次强制暂停。它是装配层，不是第二套白皮书。

## 二、用 NTF v4 生产销售内容

默认以一份销售母稿带出同一主张的衍生内容。用户只要当前一种内容时，只生成这一种，不默认制造十份文件。

### 母稿结构

1. 注意：用目标客户正在经历的场景或反差判断抓住第一眼；
2. 兴趣：让客户看见问题与自己有关；
3. 信任：用真实标准、过程、案例或证据建立可信度；
4. 渴望：说明方案、关键不同、使用后的具体变化；
5. 行动：先化解最大阻力，再给一个清楚的下一步。

### 四层改造

- 说服：检查连接、可信度、对比和真实行动理由；
- 温度：同时出现“你、我、这件事”，把抽象利益落到生活动作；
- 可读：标题有判断，长短句交替，叙事、解释和行动段按内容自然分段；
- 品牌：读取企业资料中的代表表达、核心判断和禁用表达，在生成时自然使用。品牌判断是加分项，不能压过销售任务。

不得编造案例、数字、身份经历或稀缺理由。资料没有时，使用不依赖该事实的表达，或在成品末尾集中列出最值得补的一项。

### 可调用的产物

- 销售信／长销售页：先形成完整母稿；
- 详情页：把母稿压缩成逐屏任务；
- 朋友圈／群发／发售序列：从母稿抽取，不另起一套主张；
- 小红书／公众号文章：按渠道阅读习惯改写，核心判断不变；
- 短视频销售脚本：把母稿压缩成开场、冲突、证明、方案、行动，并给可拍镜头；
- 图片套装：围绕第一眼、解释、证明、行动分工，不只换背景。

### 生成后的白盒说明

成品后用普通话说明三件事：

1. 这版先抓住客户的哪个时刻；
2. 用了什么事实或办法让他相信；
3. 先化解了哪个不行动的理由。

不要向用户展示 AITDA、FABE、F1—F5、心理账户、方法指纹等内部名词。用户主动问“为什么这样写”时，展示上述真实判断和对应原文。

## 三、和复盘的连接

后台记录本次使用的生产线、方法版本、母稿版本、关键表达动作和唯一测试变量。增长负责人复盘时先看结果发生在哪个环节，再判断：客户时刻没抓住、证明不够、阻力没化解、行动不清楚，还是渠道与内容不匹配。

复盘不能因为数据差就推翻整套方法；每轮只形成一个最值得验证的改动，交回下一轮策略或生产。
