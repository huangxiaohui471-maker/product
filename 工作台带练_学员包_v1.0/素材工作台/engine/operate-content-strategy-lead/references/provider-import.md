# 广告情报供应商导入

供应商真实导出字段可以不同，适配器支持常见中英文别名。最少需要素材/广告/创意 ID（缺失时自动生成）、原视频链接/素材详情链接/视频下载地址三者之一；最好保留投放平台，以便选择媒体补全连接器。

第三方的预估曝光、预估消耗、跑量分、计划数和投放天数永远进入 `estimated_metrics`，不能写成官方投放真值。文件名和 provider 参数不能证明来源；默认保持未验证，核验确为供应商原始导出后才允许显式升级。媒体分析权利未确认时生产下载必须阻断。

支持 XLSX、CSV、TSV 和 JSON。先用真实样例导入，根据未识别字段补别名，不要修改下游视频分析契约。
