# 状态与路线

六环固定为发现、判断、生产、触达、复盘、升级。策略负责人拥有发现和判断；生产负责人拥有生产；增长负责人拥有触达、复盘和升级候选；总控拥有编排、合同验收和跨岗冲突。

`waiting_permission` 只等待必须由用户完成的账号登录或外部授权；`waiting_result` 等真实市场结果；`missing_context` 退回企业底稿；`tool_failure` 保留失败并选择重试或降级。系统先给首选结果并自动接棒，不把选方向、采用版本或填写理由设成日常审批关卡。

总控可从中间进入，但不能跳过前置事实：已有明确策略可直接生产；已有作品可直接触达；已有发布和结果可直接复盘。进入中间环时必须标记哪些上游信息是历史事实、哪些未知。
