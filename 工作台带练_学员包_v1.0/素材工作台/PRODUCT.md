# Product

## Platform
web

## Users
企业AI课程讲师、老板、内容负责人及非技术学员。

## Product Purpose
把已有素材、拆解、作品、版本、业务资料、数据与分析放在一个方便查看和操作的工作台里。用户按当前需要进入某一工作区，不需要按轮次推进。

## Current user decision
2026-09-16：工作台和飞轮是不同层次。当前教学先做工作台，之后再讲它如何与飞轮连接。不能用后台飞轮状态或“下一轮”组织当前工作台。保留侧栏，按实际工作对象组织内部页面。

## 0.6 用户纠正后的设计原则

先判断用户正在浏览、选择、深入查看、编辑还是比较。默认展示素材库、内容列表和数据表，点击后才进入具体对象；对照参考与历史版本按需打开。不能假设用户已选定任务，不能用固定多栏承载所有状态。返回保留筛选、选择、滚动和草稿。保留四区侧栏结构。

2026-09-17 配色要求：苹果或小米风格。采用苹果式浅色工作台：浅灰画布和侧栏、白色内容区、深灰字、蓝色操作与选中，避免深蓝大色块和米黄金装饰。

## Page contracts
- 素材与拆解：查找和比较素材，查看原片、拆解与借鉴依据，按需制作内容。
- 我的内容：阅读作品、查版本、复制、修改和保存；跨区操作按需使用。
- 数据与复盘：数据总览、内容明细、复盘报告。可导入或补数据，筛选、比较、查看报告、要求分析和纠正；各项工作可以独立完成。
- 我的业务：查看已整理的理解及来源，补充和纠正。

## Constraints
页面保存要求，宿主Agent执行后回写。不假造自动调用或市场结果。原始资料、已采用版本、结果与报告历史保留。数据导入不强制分析，分析完成不自动派生产任务。后台已有飞轮能力留作之后明确要求的联动，不作为当前产品前台的组织方式。
