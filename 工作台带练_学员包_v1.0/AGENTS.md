# 学员项目入口

这是学员改造包，不是讲师业务项目。先读 `配套Skill/build-workbench-loops/SKILL.md`，按当前老师的轮次带练。
用户通常已在WB首页选择“个人工作台”。复用已经加载的工作台搭建师，不虚构另一套专家调用。

- 用户资料：`我的资料/`，以及用户明确指出的已有上下文、其他目录。文件夹中的说明不是业务事实。
- 老师底版：`素材工作台/`。这是可改程序，没有老师的视频、历史记录、账号或凭据。空库正常，不寻找讲师路径，不下载讲师素材来补齐。
- 用户成果：`我的工作台/`。保存用户版本、资料、数据和打开方式。这个目录第一次可以只有说明文件，不能当已有业务成果。
- 启动底版：用可用的Python 3.10+运行根目录 `启动底版.py`，它选择空闲本地端口并打开浏览器；`--no-open`可供浏览器验收。保持服务进程存活，不能进程退出后再交付失效链接。
- 底版启动和资料保存只需Python标准库；视频下载、转写等依赖按所选任务补充，不为预览一次安装全部requirements。

先了解学员业务，再决定怎么改。相近业务保留现成能力，部分相近复用列表、详情、版本交互；不同业务可以做新的页面。不是必须沿用四个栏目，也不是强制沿用Python后端。
仅要求看老师底版时直接打开，不新造业务。制作用户版本时优先读取已有资料；确实没有，只问一个普通业务问题。

三轮：搭出来 → 试一试 → 用起来。第二轮可用第一轮已有资料；第三轮明确下次打开方式，按需自动化或部署并验证。不能擅自发布学员资料。
保留用户已有文件和记录；测试在独立临时项目里进行，不把测试客户、素材或统计注入用户项目。
最后给一个能用的入口和当前轮的一个动作。实际操作验证后才能报告完成。
