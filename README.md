# 全球选品平台｜策略台本地整合版

这是从原 WorkBuddy 选品平台复制出的独立本地副本。

- 原始文件未被修改。
- 本地页面不会写入 WorkBuddy 数据库。
- 原有全球数据看板、商品榜、产品分析、成分库和产品设计分析均保留。
- “策略台”已升级为六步流程：决策工作台、市场机会池、AI 产品方向、方案决策与模拟、一键落地、验证与复盘。
- 按《数据采集配置手册》拆成四层证据：市场规模、带货结构、用户声音、种草内容；不同来源不混用为同一个结论。
- 市场 GMV 仅允许权威主口径支撑；其他榜单数据用于销售结构和商品线索，不会自动等价为市场规模。
- 机会入池采用 `GSP-Opportunity v2.1`：来源可追溯、时效可验证、有效样本≥20、Top50 覆盖≥40%、增长中位数≥20%、正增长占比≥60%、核心完整率≥80%、可确认增长商品≥3。
- 未知数据显示“待验证”，不当作 0，也不会被补齐成确定性结论。商业支持分与数据置信度分开显示。
- 决策链采用“AI 发现候选线索 → 人工填写理由并确认入链 → AI 生成 2–3 个产品方向 → 人工选定方向”。未入链前锁定第 3–6 步，未选定产品方向前锁定第 4–6 步。
- 人工入链和暂缓记录包含判断理由与时间，仅保存在当前浏览器本地。AI 不会因为发现增长信号就自动跳转或默认选中“眼油”等具体产品。
- 策略台右上角搜索已接入人工检索流程：输入后停顿或按回车，自动进入检索结果与人工审核页，但不会自动立项。已增加“洗面奶↔洗面乳/洁面/面部清洁”等基础同义词映射。
- 第二步已简化为单一“市场机会检索”：用户只需选择类目、国家和平台，具体商品/品牌/ID/链接作为选填条件。
- 系统会自动检索已有数据，并输出可比样本、榜单样本销量与 GMV、稳健增长、品牌集中度、机会摘要和数据缺口。数据不足时可一键生成补充采集任务草稿；任务不会伪装成已经完成真实抓取。
- 平台支持“自动匹配可用平台（推荐）”。如果用户指定的平台没有该类目数据，系统不会把其他来源混算或改写来源，而是明确提示同国家、同类目下有哪些可用来源及样本数，并可一键切换后继续分析。
- 产品方向、方案模拟、一键落地和复盘结构均可在正式立项前预览；“人工确认进入决策链”只改变项目状态和执行权限，不再把后续页面锁住。
- 本地版从 `cloud_platform.json` 加载数据，并与浏览器本机导入记录按“来源 + 国家/地区 + 商品 ID（无 ID 时用商品名）”合并；人工检索与自动机会发现共用同一数据底座。
- 当前 JSON 有 800 条记录：原有 400 条本地快照，加上从抖音罗盘商品榜新采集的 400 条商品记录。它不是 WorkBuddy 云端实时同步；知识库、供应链成本周期和复盘结果暂为模拟数据，页面内已明确标识。

## Product-Research-Tool 数据采集接入

已把公开仓库 `LI-JY-Beginner/Product-Research-Tool` 的采集核心接入本地副本，来源提交为 `7e91a3f437c43d4d574622ab0e702856f661df24`。接入范围是 `vendor/product_research_tool/collector/` 中的浏览器桥接、抖音罗盘商品榜、类目挖掘、价格带采集，以及蝉妈妈成分/功效页采集器；数据适配器为 `vendor/product_research_tool/sync.py`。未引入仓库里的另一套前端、策略推断或 LLM 流程，原 `index.html` 和既有决策链未改。上游另一个 `compass_growth.py` 用商品名称跨期匹配并以金额区间中点计算增长，不能当作精确商品环比写入现有工作台，因此未作为决策指标接入。

在本目录执行：

```bash
python3 vendor/product_research_tool/sync.py --dry-run
python3 vendor/product_research_tool/sync.py --collect
python3 -m unittest vendor/product_research_tool/test_sync.py -v
```

`--collect` 需要本机 `127.0.0.1:10086` 浏览器桥接正常运行，且相关后台已由用户登录。采集原始 JSON 保存在 `vendor/product_research_tool/data/raw/日期/`；第一次正式同步时，适配器把同步前快照备份为 `cloud_platform.base.json`，再按“来源 + 国家 + 商品 ID”去重写入 `cloud_platform.json`。重复执行不会不断追加同一商品。页面仍由本地 `http://127.0.0.1:4174/` 读取；没有写入 WorkBuddy 线上版本。

本次成功采集抖音罗盘「面部洗护」「眼部护理」各 200 条商品榜、100 条类目挖掘数据、5 条价格带数据。只有 400 条**商品榜**映射到现有看板；类目挖掘和价格带只保留原始文件，尚未接入现有展示逻辑，以免把价格带误认成类目或把类目增速冒充商品增速。罗盘返回的成交金额是人民币分单位的**区间**，不是精确销售额；接口未返回成交件数或商品级环比。因此新增商品的精确销售额、销量、环比、品牌字段保留为空，金额上下界、店铺、榜单名次、统计周期和商品链接单独保留。这些缺口不会自动满足策略台的增长与立项门槛。

蝉妈妈采集器已修复页面地址配置，但当前浏览器会跳转到蝉妈妈登录页，未能完成实际成分采集；需要手动登录后台后重试。公开仓库此次没有可直接并入的 FastMoss 采集器，也没有供应链报价接口，所以这两类数据仍沿用原本地数据/模拟边界，不能视为新接通。
