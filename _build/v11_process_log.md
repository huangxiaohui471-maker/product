# V11 过程日志 · 全球看板与榜单中心专项

## 0. 需求与边界复述（≤8 条，先复述再动手）

1. **范围只有两页**：只优化「全球看板」「榜单中心」；不重构「品类与成分库」「机会洞察」「口碑诊断」，不改导入流程 / 云表结构 / API 接入；其余导航与在线离线能力保留；基于 V10 递进，版本 V11。
2. **两页各答一问**：看板答「去哪里看」（国家/地区 × 品类的 Top50 榜单样本覆盖、销售结构、稳健增长、更新时间）；榜单中心答「具体谁在卖」（按国家、平台/来源、品类看 Top50 商品）。
3. **不许合并**：不同平台 / 币种 / 统计周期绝不直接相加；Top50 占比只能叫「Top50 榜单样本 GMV 占比」或「样本结构占比」，不能叫「市场份额」；没有可比口径就不出跨国金额结论。
4. **不许造数**：缺失的销量 / GMV / 价格 / 增速一律显示「—」不当 0；只按真实覆盖显示；字段不支持近 30 天口径时如实降级并标注实际周期。
5. **示例隔离**：两页默认走真实数据，有真实数据时 40 条示例不得进入默认 KPI / 热力图 / 榜单，示例切换与标记保留。
6. **增长口径统一改规则级**：分组资格、排序、Hero、卡片、表格必须用同一个稳健指标（中位数或截尾均值），并展示样本量、正增长占比；低基数 / 新品 / 零基期排除或显著标注。
7. **必测反例**：印尼 × 唇妆 7 条增速 `[-40.09, -0.86, 10.06, 18.16, 36.39, 160.77, 57725]`（均值 8272.78%、中位数 18.16%）不得再因此班判为「≥60% 集体起量」，也不得在排序或 Hero 中误导。
8. **界面与验收**：延续 V10 高级轻盈风格不换皮；390px 不依赖横向筛选长条，改「筛选」按钮 / 抽屉 + 已选 chips；触控 ≥44px、无页面级横向溢出；本地跑完全部验收（含 4 张截图、0 JS 报错、断言型脚本非零退出）再上线，最后报告改动文件 / 口径 / 测试结果 / 截图路径 / 未解决限制。

## 1. 冲突说明（先说明，不擅自扩范围）

- 硬约束 6 要求「分组资格」也用统一稳健指标，而「市场机会」这条规则的判定逻辑位于 `insightsOf()`（同时供「机会洞察」视图使用）。**按 spec 要求改规则本身，而不是只换展示文案**，因此该函数的「市场机会」判定会被改动，机会洞察页显示同一结论——这是 spec 明确要求的必然结果，不视为扩范围。
- 硬约束「390px 不依赖横向筛选条」而筛选条 `#chips` 是三个视图共用的组件，改造后「品类与成分库 / 机会洞察」在小屏同样受益（桌面端表现不变）。属维持两页正常渲染所必需。

## 3. 未解决限制（如实上报）

1. **蝉妈妈 / FastMoss 的「数据截至」整列拿不到**：两来源的「榜单排名」文本不带日期区间（FastMoss 是 `TikTok 日本护肤第 3` 这种格式），该列按「来源给不出就不出」整列不渲染，覆盖度条里以「周期 …」标注；只有抖音罗盘 60 条带 `2026/09/12 ~ 2026/09/18`。
2. **FastMoss 真实数据 250 条全部缺「销售额」**（示例数据反而有）：来源能力上算可得，因此保留该列 + 覆盖度条显示「有金额 0/250」——这是采集缺口，不是来源不给；要补齐需重跑 FastMoss 取数。
3. **「稳健增长中枢」全库中位数为 0%**：291 条有增速样本里正增长只占 41%，中位数 0 是事实，Hero 首屏 KPI 会显得「不好看」，但这是真实口径（V10 的 +288.3% 均值是错的）。
4. **跨源/跨币种金额结论仍然出不来**：库里没有「币种」字段，`comparableGmv` 只在单来源 + 单周期内放行（蝉妈妈 50 条可算）。待拍板项「汇率折算」不解决前不变。
5. **韩国（Hwahae / Olive Young）真实数据仍为 0**：分来源分榜 Tabs 不会出现这两个来源，只有显式「只看示例」才能看到其榜单形态；机会规则照旧算不出韩国。
6. **Hero 最优格最少 3 个样本**：`MKT_MIN_SAMPLE=3` 沿用 V10，本轮只统一了指标没动样本门槛；首屏会推一个 3 样本的「印度尼西亚·底妆 +217.5%」。若嫌薄，下一步可把门槛升到 5（一处常量）。
7. **口径表未升 v1.8**：V11 没有改任何字段定义（FIELDS 仍是 42 个、云表结构未动），改动全在统计与展示口径。是否要把「稳健增长中枢 / 分来源分榜 / 可比样本 GMV」写进口径表新 sheet，留待拍板。
8. **机会洞察 / 品类与成分库的视图代码未重构**（spec 要求不动），但其读到的「市场机会」结论已随规则级修改而变化——属 spec 明确要求的必然结果（见 §1）。
