# Chancev1｜实验工厂机会雷达

这是一个与原有全球看板和策略台相互独立的 MVP Demo，用于验证新的产品主线：

```text
真实用户信号 → 候选机会 → 机会审判 → 最小实验 → 继续 / 调整 / 观察 / 淘汰
```

## 当前功能

- 机会雷达：以空间画布和候选卡展示每日最多 3 个值得关注的机会。
- 多路径召回：重复需求、强行为、异常变化、高价值例外；不使用硬分数线淘汰机会。
- 持续观察：展示每个候选当前缺少的关键证据，并支持提前送审。
- 等待审判：支持立即审判、退回观察和淘汰。
- 机会审判：分开呈现支持证据、反证、AI 推断和最大未知。
- 小实验室：生成最低成本实验并演示结果和下一步动作。

## 数据说明

当前所有候选、数量、证据和实验结果均为演示数据，尚未连接天猫、小红书或原平台本地数据库。

## 本地运行

在 `Chancev1` 目录执行：

```bash
python3 -m http.server 4176 --bind 127.0.0.1
```

浏览器访问：

```text
http://127.0.0.1:4176/
```

核心原型文件位于：

```text
实验工厂机会雷达/原型/实验工厂机会雷达-prototype.html
```
