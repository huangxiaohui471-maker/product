## 名词解释（源自墨刀敏捷版 PRD 的「名词解释」章节）

| 术语 | 定义 | 为什么需要定义 |
|---|---|---|
| **信号** | 从原始数据中按固定规则识别出的一个可量化事实（如「某商品环比增速 +122%」）。信号本身**不等于**机会。 | 现状把「增速高」直接当「是机会」，这是本次要纠正的 |
| **候选机会** | 一个商品 + 一个主假设（如「国外爆品但国内空缺」）+ 一组信号。是**待验证物**，不是结论。 | 明确"候选"与"结论"的分界 |
| **主假设** | 该候选为什么可能是机会的那一句话。每个候选**有且只有一个**主假设。 | 避免一个卡片堆砌互相矛盾的多个理由 |
| **证据链** | 支撑**或推翻**主假设的原始记录集合，每条都能指回具体商品与具体字段。 | 用户要求「可追溯到原始数据」 |
| **反向证据** | 指向"这个机会可能不成立"的原始记录。**必须展示，不允许隐藏。** | 对应录音：「有时结论是机会不在这里，本次调查虽然淘汰了一个候选，却让系统对市场的认识前进了」 |
| **判定档位** | 对主假设成立程度的结论：`成立` / `待验证` / `证据不足`。**不输出单一总分。** | 对标调研发现 Helium 10 的"7 分即好机会"不可解释，本次明确不用 |
| **阻断项** | 一旦存在就**不可**判定为「成立」的硬性事实（如增速为负、名次下降、样本不足 5 条）。 | 让"否决"有据可依 |
| **跨市场缺口** | 同一品类 × 形态在 A 市场有供给且已成交、在 B 市场无供给记录。 | 本次核心新增概念 |
| **空白 ≠ 没采集到** | 「B 市场没有该商品」有两种可能：真空白，或**我们没采到**。两者必须区分展示。 | 现有美国侧仅 14 条真实数据，误判风险极高 |

## A · 为什么做

### A.1 业务背景：现有页面的三个具体故障

**故障 1 · 页面永远是空的。**
现有 `opportunityRows()`（L3463–3486）只把**当天首次观测到**且 `rec.baseline === false` 的商品计入候选。而 `opportunityObserve()`（L3409–3430）在**第一次运行时把全部存量记录都写成了 `baseline: true`**。结果是：只要不出现"今天新采到、昨天没采到"的商品，`candidates.length` 恒为 0，页面恒显示「今天还没有可确认的新品机会」。**这是一个逻辑死锁，不是数据问题。**

**故障 2 · 判断标准是机械单维的。**
现有代码只有两个入选通道：
- 海外侧：`环比增速` 有值 → 按增速降序取前 3（L3469–3473、L3483）
- 国内侧：`是否新上榜 === 'true'` 且 `成交金额` 有值 → 按金额降序取前 3（L3475–3480、L3484）

即：**"是不是机会"被简化成"增速够不够高 / 是不是新上榜"**。而需求方明确否定了这一点：

> 「这是一个很多维的判断标准，不只是拿增速来判断它是不是一个有机会的产品。」

**故障 3 · Tab 口径与业务口径不一致。**
现有 Tab 是「美国 → 中国 / 中国 → 美国」（`data-opportunity-tab`，L3537–3539），描述的是**信号流向**。而需求方要的是按**机会落点**分：

> 「国内产品机会，这里就放国外爆品但国内空缺，然后国外机会就放国内火但国外没有。」

### A.2 业务背景：为什么"多维"是必须的

需求方给出的四类机会形态，**没有一类能被"增速"单独识别**：

| 需求方原话 | 本质 | 为什么增速识别不了 |
|---|---|---|
| 「在国外市场它是一个爆品，但是在国内它是一个空缺」 | **供给缺口** | 缺口品在国内可能根本没有榜单数据，**没有增速可算** |
| 「国内卖得很火，但国外还没有出现过这个」 | **供给缺口（反向）** | 同理，海外无记录则无增速 |
| 「这是一个增长很快的新品」 | **速度 × 品龄** | 只看增速会把"上架 3 年的老品在清仓冲量"误判成新品 |
| 「有商品出现了新包材」 | **形态创新** | 增速完全测不到包装形态，**必须看标题/图文** |

### A.3 目标与成功指标

| 指标 | 现状 | 目标 | 测量方式 |
|---|---|---|---|
| 页面有候选商品的比例 | **0%**（逻辑死锁，恒空） | 两个 Tab **各 3 个**候选 | 打开页面肉眼计数 |
| 判断维度数 | 1 个（增速） / 1 个（是否新上榜） | **≥7 个信号维度**，逐个可展开 | 数卡片上的信号标签 |
| 每个候选可追溯的证据条数 | 1 条（仅有增速或金额） | **每条信号都能展开到原始记录** | 点击展开，比对 `cloud_platform.json` |
| 误判为"机会"却实为"没采到"的风险 | 未识别，**静默** | 显式标注「空白 ≠ 没采集到」 | 检查无数据 Tab 的文案 |
| 首屏到看完 6 个候选的时间 | 不可用 | < 2 分钟 | 需求方自述 |

### A.4 不做会怎样

- 第一张看板继续是空页，需求方每次打开都要跳过它——**入口失效**
- 继续用增速单维筛选，会持续漏掉需求方最看重的**跨市场缺口**与**新包材**
- 美国侧 14 条真实数据会被当成"美国市场全貌"，得出**方向性错误的结论**（这是比空页更危险的失败模式）

### B.2 使用场景

| 场景 | 触发 | 期望动作 |
|---|---|---|
| **每日巡盘（主场景）** | 上班打开平台 | 切两个 Tab 各扫 3 个候选，挑 1–2 个进入「市场机会检索」深挖 |

### B.3 范围边界

**本期做：**
- 把「今日产品机会」改造为「产品机会雷达」，含**国内市场机会 / 国外市场机会**双 Tab
- 每 Tab 输出 **3 个候选**，候选带主假设、多维信号、证据链、反向证据、判定档位、下一步
- 引入 **7 个信号维度**（见 C.3）
- 锁定类目：**眼部护理 + 面部洗护**；锁定国家：**中国 + 美国**
- 数据源：中国侧 **抖音罗盘（主）+ 蝉妈妈（补增速与上市日期）**；美国侧 **FastMoss**
- FastMoss 美国数据**补采**（经本机浏览器桥接，复用登录态）

**本期明确不做：**
- ❌ **不输出单一机会总分**（对标调研已论证不可解释）
- ❌ **不引入利润模型**（FBA 费用 / 毛利 / ACoS）——口径属亚马逊，且本地 `预估成本` 仅 40 条
- ❌ **不引入 Google Trends / 搜索量 / 海关数据**（无稳定来源，且与成交口径互相污染）
- ❌ **不做"自动立项"** —— 判定只是线索，立项仍走策略台人工入链（沿用现有 `stCommitMarketAnalysis` 流程）
- ❌ **不做历史趋势折线** —— 需多期快照，当前中国侧仅 1 个快照日、美国侧无历史版本
- ❌ **不新增数据源**（不加飞瓜、不加 Hwahae/Olive Young）
- ❌ **不改动**全球数据看板 / 商品榜 / 产品分析 / 成分库 / 产品设计分析 / 策略台

## C · 做什么

### C.1 页面结构图

```
产品机会雷达（VIEWS[0].key = 'opportunity'）
│
├── 页头
│   ├─ 标题「产品机会雷达」
│   ├─ 副标题（本页判定的性质声明：只给候选，不给结论）
│   └─ 数据新鲜度条（各来源最近快照日期 + 真实记录数）
│
├── Tab 切换
│   ├─ [国内市场机会]  ← 主假设：国外有供给、国内空缺
│   └─ [国外市场机会]  ← 主假设：国内有供给、国外空缺
│
├── 候选区（当前 Tab 内，固定 3 张卡片，纵向排列）
│   └── 候选卡片 ×3
│       ├─ ① 序号 + 机会类型徽标 + 判定档位徽标
│       ├─ ② 商品名 / 品牌 / 品类 / 二级类目 / 目标市场 / 数据来源
│       ├─ ③ 主假设（一句话）
│       ├─ ④ 触发信号清单（N/M 命中，每条带原始数值）
│       ├─ ⑤ 证据链（默认折叠，可展开成原始记录表）
│       ├─ ⑥ 反向证据（默认展开，不允许折叠）
│       └─ ⑦ 下一步最该查什么
│
└── 页脚
    ├─ 判定规则说明（阈值可查）
    └─ 数据缺口声明（哪些维度本市场拿不到）
```

### C.2 机会类型定义（候选的 4 种类型）

| 类型码 | 名称 | 主假设句式 | 中国侧可否判定 | 美国侧可否判定 |
|---|---|---|---|---|
| `GAP` | **跨市场缺口** | 「X 在〔信号市场〕已成交〔金额/销量〕，在〔目标市场〕同类目×同形态无供给记录」 | ✅ | ✅ |
| `VELOCITY` | **高速增长** | 「X 环比增速 〔g〕%，高于同类目可比样本中位数 〔m〕%」 | ⚠️ 罗盘无增速，须走蝉妈妈 | ✅ |
| `NEWFORM` | **新形态/新包材** | 「X 标题含形态信号〔词〕，同类目其他在榜商品未出现该形态」 | ⚠️ 文本抽取 | ⚠️ 文本抽取 |
| `RANKUP` | **榜单地位跃升** | 「X 榜单位次较上期上升 〔n〕 位」 | ⚠️ 名次变化仅 22/100 | ✅ |

> **排序规则**：先按类型优先级（`GAP` > `VELOCITY` > `NEWFORM` > `RANKUP`），同类型内按判定档位（`成立` > `待验证` > `证据不足`）排序，再按信号命中数降序。**这是为了让"跨市场缺口"这个需求方最看重的类型优先露出。**

### C.3 信号维度清单（7 个）

| 编号 | 信号名 | 英文 key | 判定「命中」的口径 |
|---|---|---|---|
| **S1** | 跨市场缺口 | `gapSignal` | 目标市场下，同「二级类目 × 形态词」的记录数 = 0，且信号市场下 ≥ 3 条 |
| **S2** | 高增长 | `growthSignal` | 环比增速 ≥ 同类目同来源样本中位数，且 > 0 |
| **S3** | 新品 | `freshSignal` | 品龄（今天 − 上市日期）≤ 180 天 |
| **S4** | 榜单地位 | `rankSignal` | 榜单排名 ≤ 30，或名次变化为上升 |
| **S5** | 形态/包材 | `formatSignal` | 标题命中形态词典，且该形态在同类目其他在榜商品中出现率 < 30% |
| **S6** | 需求验证 | `demandSignal` | 评价数 ≥ 1,000，且评分 ≥ 4.3 |
| **S7** | 达人放大 | `reachSignal` | 关联达人数 ≥ 20 |

**各市场信号可得性（真实数据实测）**：

| 信号 | 中国 · 抖音罗盘 | 中国 · 蝉妈妈 | 美国 · FastMoss |
|---|---|---|---|
| S1 跨市场缺口 | ✅ 可算 | ✅ 可算 | ⚠️ 样本薄，结论须标注 |
| S2 高增长 | ❌ **环比增速 0/100** | ✅ 41/50 | ✅ 有 |
| S3 新品 | ❌ **上市日期 0/100** | ✅ 50/50 | ✅ 有 |
| S4 榜单地位 | ✅ 榜单排名 100/100；⚠️ 名次变化 22/100 | ✅ 有 | ✅ 有 |
| S5 形态/包材 | ⚠️ 标题抽取 | ⚠️ 标题抽取 | ⚠️ 标题抽取 |
| S6 需求验证 | ❌ 无评价数/评分 | ❌ 无 | ✅ 289 条有 |
| S7 达人放大 | ❌ 无关联达人数 | ❌ 无 | ✅ 283 条有 |

> ⚠️ **这就是"多维"的真实代价**：中国侧的 S2/S3/S6/S7 拿不到。系统必须**如实显示"该维度本市场无数据"，而不是跳过或补零**——沿用现有 `README` 已确立的原则「未知数据显示'待验证'，不当作 0」。

### C.4 判定档位规则（可客观验证，无形容词）

| 档位 | 触发条件（全部满足） |
|---|---|
| **成立** | 命中信号数 ≥ 4 **且** 无阻断项 **且** 主假设所需证据齐全 |
| **待验证** | 命中信号数 2–3 **且** 无阻断项 |
| **证据不足** | 命中信号数 ≤ 1 **或** 存在任一阻断项 |

**阻断项清单（硬性）：**

| # | 阻断项 | 判定 |
|---|---|---|
| B1 | 本市场可判定信号数 < 3（拿不到的信号不计入分母） | 无法形成判断 |
| B2 | 环比增速为负 | 需求在萎缩 |
| B3 | 名次变化为下降且降幅 ≥ 10 位 | 正在被淘汰 |
| B4 | 目标市场同类目真实记录数 < 5 | 空白无法区分「真空白」与「没采到」 |
| B5 | 商品名命中赠品/非卖品模式 | 非独立商品（沿用现有 `opportunityIsExcludedNewProduct()` 正则） |

### 三、缺口判定升级：从「绝对为零」到「供给密度差」

草案 S1 只认「目标市场记录数 = 0」。实测发现两类误判，故升级：

1. **绝对空缺**：目标市场同一**细分族**该卖点 0 条 → 仍是最强证据
2. **供给密度差**：信号市场密度 ≥ 目标市场密度 × 3 且达到下限（同二级类目 8%／锁定类目整体 5%）
   → 例：PDRN 在美区眼部护理占 23.1%，国内只占 2.6%（1/9），这是草案规则会漏掉的真实缺口

**两级口径**（先严后宽）：
- 一级：**同二级类目**（如 眼部护理 ↔ 眼部护理）
- 二级：**锁定类目整体**（面部洗护 + 眼部护理合并），用于成分型趋势跨细分共用的情况

**三道防误判闸门**（缺一不可）：
- 卖点须在信号市场出现 **≥3 条且来自 ≥2 家店铺**（排除单一品牌灌水）
- 目标市场同一细分族须有 **≥5 条**记录，否则视为「没采到」（罗盘面部洗护 TOP200 里没有防晒品类，就是这种情况）
- 只允许**有区分度的形态 / 成分**参与缺口判定；玻尿酸、胶原、胜肽、烟酰胺等全行业通用词不构成缺口

**两类特殊处理**（如实展示，不掩盖）：
- **宣称口径受限**：中国未收录「抗衰老」功效宣称，国内标题只用「抗皱」→ 不作缺口证据，标为「宣称口径差异」
- **成分合规阻断（B6）**：如 EGF（人寡肽-1）列入中国《化妆品禁用原料目录》，
  该缺口由监管造成、不可复刻 → 直接排除出候选，记入 `exclusions`

**且 3 张卡的「主缺口卖点」不重复**（不足 3 张时按序补位），避免三张卡讲同一件事。
