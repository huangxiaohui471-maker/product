## 确认要点

这 4 张线框图是**低保真**，只讲信息层级与布局，不讲美观。请确认：

1. **信息层级对不对**？（比如商品详情页的六屏顺序是否合理）
2. **字段全不全**？（比如榜单中心的表格字段是否够用）
3. **路径通不通**？（比如从榜单中心点击商品名能否跳到商品详情页）

确认后，进入高保真视觉稿（或直接进开发）。
